# Baseline results, suite factorysim-2.0 (test split, 3 seeds per instance)

Suite 2.0 is built on the people-free reference lab (arm robots; stations without operators; no technician).
Generated with `factory-sim generate --splits test` (FactorySim 2.0.0),
`factory-sim bench --suite benchmarks/v2.0 --split test --seeds 3 --policy <p>` and `factory-sim table`.
Cells: success rate / mean makespan over `best_known` (successful runs). `best_known` comes from nominal-duration runs
without disturbances, so stochastic runs can beat it (ratio < 1) and families with disturbances show larger ratios.
`cpsat`: CP-SAT schedule (10 s) executed open-loop, run on `exact`, `base` and `bottleneck`; within 10 s it finds a
schedule for few M / L instances.
